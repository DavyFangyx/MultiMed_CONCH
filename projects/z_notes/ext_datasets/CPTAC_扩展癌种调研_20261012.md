## 三、逐模态详细结论

### 3a. WSI(IDC,全部公开 CC BY 4.0)

- 所有 CPTAC collection 均存在于 Imaging Data Commons v3 API(`https://api.imaging.datacommons.cancer.gov/v3/collections`),格式为 **DICOM Slide Microscopy(SM)**,由 SVS 转换(dcm2sm,Zenodo 托管元数据,如 GBM: 10.5281/zenodo.12666788,OV: 10.5281/zenodo.12666842)。
- 实测匿名直链可读:`https://idc-open-data.s3.amazonaws.com/{crdc_series_uuid}/{crdc_instance_uuid}.dcm` → HTTP 206(支持 range 读取,无需凭证)。
- **无 WSI 的只有 STAD**(cptac_stad 仅 CT/US 影像)。SAR 有 WSI 但 GDC 无 RNA。

### 3b. RNA(GDC)

- CPTAC-3 共 **2968 个** `data_type=Gene Expression Quantification` + `analysis.workflow_type=STAR - Counts` 文件,分布见上表;CPTAC-2 共 340 个。所有队列(除 SAR)RNA 齐全,文件数略多于病例数(部分病例有多份肿瘤/正常/重复样本)。

### 3c. 临床与生存(实测结论,按优先级)

**关键发现:cBioPortal 已上线全套 "CPTAC GDC 2025" 新版 study(hg38),这是目前最优的 CPTAC-3 生存来源;旧版(hg19,luad_cptac_2020 等)实测患者级只有 AGE、无任何生存字段,不要用。**

| study | 患者 | OS_STATUS | OS_MONTHS(仅死亡病例) | DAYS_TO_DEATH |
|---|---|---|---|---|
| luad_cptac_gdc | 230 | 208/208 | 57/57 | 57/57 |
| lusc_cptac_gdc | 109 | 104/104 | 33/33 | 33/33 |
| uec_cptac_gdc | 241 | 228/228 | 35/35 | 35/35 |

**注意**:OS_MONTHS 只对死亡病例有值;存活(0:LIVING)病例没有随访时间字段。删失时间用 **GDC `days_to_last_follow_up`** 补齐——本地 CPTAC-3.json 实测 1731/1866 例非空,按队列:LUAD 206/230、LSCC 104/109、CCRCC 240/257、UCEC 227/241、GBM 178/211、PDA 161/163、HNSCC ~104/106、黑色素瘤 166/183、AML 173/173、STAD 165/165。patientId(11LU013、C3L-xxxxx、01OVxxx)与 GDC submitter_id 一一对应,可直接 join。

**GDC 的 `diagnoses.vital_status` 和 `diagnoses.days_to_death` 在 CPTAC-3 病例中根本不存在字段**(API 报 unrecognized fields;CPTAC-2 同理全部为空)——与 breast 经验一致,GDC 单靠自身无法给死亡事件。

**LinkedOmics(实测):** 旧链接 `/data_download/CPTAC-3/` 已 404,新位置是 pancan 页面 `https://linkedomics.org/data_download/CPTAC-pancan-{CANCER}/`(LUAD/LSCC/UCEC/CCRCC/GBM/HNSCC/OV 均 200,PDA/PAAD 404)。生存文件为公开 S3 直链:
`https://cptac-pancancer-data.s3.us-west-2.amazonaws.com/data_freeze_v1.2_reorganized/{CANCER}/{CANCER}_survival.txt`(LUAD/LSCC/UCEC/CCRCC/GBM/HNSCC/OV 实测 200 OK)。文件格式实测:

```
case_id  OS_days  OS_event  PFS_days  PFS_event
11LU016  445      1         445       0
C3L-02348 1425    0         1425      0
01OV026(OV) 112   1         NA        0
```

case_id 与 cBioPortal/GDC 完全对齐,OS+PFS 双终点,是**最省事的单文件生存来源**(PDA 除外)。

**PDA 生存**:LinkedOmics 无 PDA;cBioPortal pancreas_cptac_gdc 有 OS_MONTHS(死亡 129 例)+ OS_STATUS(161 例);删失时间用 GDC days_to_last_follow_up(161/163)。备选:PDC 或 CPTAC PDA 论文(Cell 2021)supplement。

**其他备选源(实测状态)**:ESAC 官方 CPTAC-3 临床 API `https://clinicalapi-cptac.esacinc.com/api/tcia/` 在本环境无法解析(网络不通);PDC GraphQL(`https://pdc.cancer.gov/graphql`)在本环境响应超时,不建议依赖。

## 四、特别结论(哪些可用/缺什么)

- **生存数据齐全(OS/PFS 事件+时间都有)**:LUAD、LSCC、CCRCC、UCEC、GBM、HNSCC(cBioPortal _gdc OS + LinkedOmics OS/PFS + GDC d2lf 三重可交叉验证);**PDA**(cBioPortal OS 时间 + GDC d2lf,无 PFS);**Ovary**(LinkedOmics OS/PFS + cBioPortal OS_STATUS)。
- **像 breast 一样 GDC 临床缺失生存的**:所有 CPTAC 队列在 GDC 均无 vital_status/days_to_death(这是普遍现象,不是个别队列问题);但 CPTAC-3 六大队列已由 cBioPortal 新版 study 补齐,不再缺。
- **完全缺生存事件的**:黑色素瘤(CM)、AML、STAD——cBioPortal 无对应 CPTAC study、LinkedOmics 无、GDC 无 death 字段,只有 GDC days_to_last_follow_up;只能找各自论文 supplement 或 PDC(不建议)。
- **完全没 WSI 的**:STAD(仅 CT/US 影像)。
- **完全没 RNA 的**:SAR(GDC CPTAC-3 无肉瘤 RNA;IDC 有 WSI)。
- **WSI 例数偏少需注意的**:Ovary(73 例)、HNSCC(112 例)、GBM(178 例,成人;brain_cptac_gdc 314 样本含儿科 CHOP 部分,IDC 无儿科 CPTAC WSI)。

## 五、下载方式汇总(实测可用)

**1. GDC RNA manifest 生成(API 两步)**

```bash
# 第一步:取 file UUID 列表(例:CPTAC-3 肺腺癌 STAR-Counts)
curl -s 'https://api.gdc.cancer.gov/files?filters=...&fields=file_id&format=json&size=1000&from=0' \
  | python3 -c "import json,sys;print('\n'.join(h['id'] for h in json.load(sys.stdin)['data']['hits']))" > ids.txt
# 第二步:POST manifest 端点得 manifest 文本,再用 gdc-client download -m manifest.txt
curl -s -X POST 'https://api.gdc.cancer.gov/manifest' -H 'Content-Type: application/json' \
  -d "{\"ids\":[...]}" > manifest.txt
```

(注意 GDC files 端点每页 size 上限 1000,2968 个文件需翻 3 页。)

**2. IDC WSI(推荐:s5cmd 或 idc-index CLI)**

- 生成 manifest:POST `https://api.imaging.datacommons.cancer.gov/v3/cohort/manifest`,body `{"filters":{"terms":{"collection_id":["cptac_luad"],"Modality":["SM"]}}}` → 返回 counts + `s3://idc-open-data/{series_uuid}/*` 清单 + 下载命令。portal 页面导出 manifest 亦可(portal.imaging.datacommons.cancer.gov)。
- 下载:`pip install idc-index` 后 `idc download-from-manifest idc_manifest.txt --download-dir ./idc-data`;或 `s5cmd --no-sign-request run manifest`(对象在 `s3://idc-open-data`,实测匿名可读)。切片为 DICOM(dcm)格式,与现有 breast/colon 管线(idc-annotations/dcm)一致。

**3. cBioPortal 数据包**

- 直链形式(实测 200):`https://datahub.assets.cbioportal.org/{study_id}.tar.gz`(如 brain_cptac_gdc.tar.gz、ovary_cptac_gdc.tar.gz)。
- **旧地址 `https://cbioportal-datahub.s3.amazonaws.com/...` 已失效(403),勿用。** tar.gz 内含 data_clinical_patient.txt / data_clinical_sample.txt。

**4. LinkedOmics 生存文件**

- 直接 curl:`https://cptac-pancancer-data.s3.us-west-2.amazonaws.com/data_freeze_v1.2_reorganized/{CANCER}/{CANCER}_survival.txt`(LUAD/LSCC/UCEC/CCRCC/GBM/HNSCC/OV 实测 200;PDA 无)。
